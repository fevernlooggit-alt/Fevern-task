我们拥有竞品罕见的好骨架——严格状态机、可靠撞单保护、逐笔 AI 成本审计、干净的多租户隔离。但客户发来消息后永远收不到任何回复：EVA 与客服的回复只存在于内部控制台。加上收件箱被维护任务刷屏、列表只显示 25 条，当前系统不可对外运营。

市场机会恰好对着我们的长处。 估值最高的 AI 原生玩家（Sierra $15B、Decagon $4.5B、Ada）共同的结构性软肋是没有人工工作台，AI 转人工时上下文割裂是全行业最一致的差评；Intercom 的头号差评是账单不可预测。我们手里恰好有两张对应的牌：AI 与人工天生同台，以及已在记账的 AI 成本逐笔审计——可打「零割裂人机同台 + 行业最透明的严格口径按解决计费」，叠加游戏行业纵深。

D7 · 最终版产品架构

「一个收件箱、一个客户真相、一个可审计的 AI 同事」

AI 处理它有把握的一切，人处理例外；两者在同一张工单、同一份上下文里无缝换手，每一次 AI 行为都有来源、成本和理由可查。

收件箱（唯一工作面）

左：可保存视图（我的/未分配/SLA 风险/VIP）；中：会话流 + 快捷回复 + AI 起草（带来源引用）；右：客户上下文栏（档案/历史/订单/情绪/建议动作）。键盘优先。

主管驾驶舱

实时队列健康、SLA 风险、坐席负载、异常聚类告警（「1 小时 14 单提充值失败」）、AI 日报推送——每条结论可下钻到底层单据。

AI 工作室

EVA 配置 → 知识库 + 缺口清单 → SOP/Playbook → 仿真回放 → 发布，配置-测试-发布闭环；每层真实健康状态可见。

行动与审计层

工具注册表 + 三档权限（自动执行/需审批/禁止）+ 审批队列 + 全审计流水；routing_logs 扩展为全 AI 行为账本，成本中心免费开放。

技术上演进式而非推倒重来：保留 Fastify/Prisma 单体、状态机、锁与多租户模型；新增出站投递层（BullMQ）、pgvector 语义检索、Action 框架、规则引擎、洞察管线；前端补 URL 路由。

D180 · 市场领先
差异化三板斧成立

AI 行动执行（查订单零人工、补发走审批）；语义检索 + 来源引用；知识飞轮；主管驾驶舱 + AI 日报；AI QA v1；流失/VIP 识别；规则引擎全量；与种子客户试点严格口径按解决计费。验收：查询类零人工解决率 ≥40%；模拟事故 30 分钟内聚类告警。

贯穿纪律：状态机/锁/审计改动必须过既有测试；每个 AI 功能带「采纳率/解决率/成本」埋点，两迭代无正向数据即降级；所有新配置必须同时有 UI 与 API，杜绝新的「后端有前端无」。

D10 · 顶层验收标准（D180 达成即「市场领先」成立）

八条最终验收

  1. 客户在任一已接渠道全程收到每条回复，投递失败可见、可重试
  2. 查询类问题 AI 零人工解决率 ≥40%，每条回复带来源引用
  3. AI→人工交接带真实摘要与建议动作，客户零重复自述
  4. 客服打开工单 3 秒内看到客户完整历史；平均回复时长较基线降 ≥30%
  5. SLA 违约自动升级且留痕；新转人工通知送达率 100%
  6. 每一次 AI 行为可查：依据、成本、模型、操作留痕
  7. 管理员不碰代码完成开号、接渠道、配规则；新租户 1 天内上线
  8. 严格口径 resolution 报表与计费对账单，逐单可核
审查方法：本地全栈部署（Postgres 16 + Redis 7 + API + React 控制台 + worker），Playwright 驱动真实 UI 以 5 种角色逐项操作并截图；LiveChat/Telegram webhook 模拟终端客户；API 边界测试与 PostgreSQL 取证；运行仓库自带 84 项单测与 e2e 冒烟。完整交付物：docs/product-review/（01 功能盘点 · 02 Bug 清单 · 03 竞品报告 · 04 差距矩阵 · 05 目标设计 · 06 P0–P3 · 07 Roadmap · 08 Executive Summary · evidence/ 截图 ×15）。按审查约定，未修改任何产品代码。
